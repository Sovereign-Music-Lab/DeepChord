# 실행 확인과 제한

[English](verification.md) · **한국어**

2026-11-08 개발 환경에서 확인한 내용입니다. 실행 검사와 사실·음악 품질을 구분합니다.

## 공개 기초 자료

독립 작성 이론 24개, 간격 공식 32개, 12근음 코드 384개입니다. RAG 408개·학습 레코드 816개의 재현, 모든 공식의 이조, Cdim7·F#maj7의 철자, 검색·출처·덮어쓰기 방지를 검사했습니다. 준비 과정에서 같은 정답을 중복 제거해 train 258 / valid 82 / test 92개가 남았습니다. 이조·언어 변형은 코드 계열 또는 이론 카드의 같은 그룹에 둡니다.

개인 교재 PDF·OCR·문장·페이지 위치·예제 악보는 공개 기초 자료의 입력이나 배포에 포함하지 않았습니다. 공개 TOML·공식으로 내보내기를 재현합니다.

## 실제 로컬 작곡 루프

설치된 Ollama `gemma4:12b-mlx`로 두 번 연속 요청했습니다. 첫 생성은 한 차례 수정 후 검사를 통과했고, 두 번째 요청은 직전 결과를 받아 반주를 수정했습니다. G7→Cmaj7 코드와 선율 음표를 유지하고 버전별 JSON·MIDI·설명·세션을 저장했습니다. 이 2마디 사례는 임의 수정의 정확성을 보장하지 않습니다.

실패 후 계속 주문, `/quit`, `/new`, 세션 재시작과 버전 보존은 별도 테스트로 확인합니다. 이번 소프트웨어 작업에서 열린 Logic 프로젝트를 변경하거나 새 곡을 청취했다고 주장하지 않습니다.


같은 세션을 재시작해 세 번째 주문에서는 로컬 LoRA 이론 검토도 함께 호출한 뒤 Ollama로 수정했습니다. 이론 검토 응답과 검사 결과가 별도 파일에 남았고 작곡 JSON·화성 검사도 통과했습니다.

## Gemma 계열 LoRA

기존 Mac의 Gemma 4 12B MLX/Ollama 텐서에서 텍스트 가중치를 로컬 작업용으로 구성했습니다. 설치 MLX의 전역 NVFP4 스케일 호환성 때문에 스케일을 적용해 복원한 후 affine int4(group 64)로 재양자화했습니다. 이 베이스는 **원래 Ollama 가중치와 동일하지 않습니다**. 텐서별 상대 RMSE 평균 약 0.0972, 최대 약 0.1228은 복원 차이이며 음악 품질 수치가 아닙니다. 원본 Ollama 모델은 변경하지 않았습니다.

공식 [Gemma 4 12B 대화 템플릿](https://huggingface.co/google/gemma-4-12B-it/blob/b5deb5d449cec28d5250a5821b0fd42f96ff5110/chat_template.jinja), 설치 `mlx-lm 0.32.2` / `mlx 0.32.4`, 프롬프트 마스킹, 마지막 2레이어, rank 8, 배치 1, 학습률 0.0001, seed 42로 실행했습니다.

| 실행 | 전체 보류 테스트 loss | perplexity |
|---|---|---|
| 20회 학습 | 4.715 | 111.647 |
| 별도 200회 학습 | 3.079 | 21.747 |

어댑터 생성·재로딩·추론은 완료했습니다. **정답 품질은 미달입니다.** 200회 어댑터의 Cmaj7·Cdim7·G7·F#m7b5 네 추가 질의에서 전체 필드 정답은 0/4였습니다. Cmaj7·G7의 음 이름은 맞았지만 음급 정수가 틀렸고 나머지에는 구성음 오류도 있었습니다. 이 작은 검사는 대표 정확도나 창의성 평가가 아니며 손실 감소가 이론 정답·음악적 개선의 증거가 아님을 보여줍니다.

LoRA 응답은 미검증 제안으로 처리합니다. 구조화한 코드 응답은 공식과 대조해 불일치를 기록하고 계산한 구성음을 우선합니다. 이 어댑터를 신뢰 가능한 이론 모델로 배포하지 않으며 다른 Ollama 태그에 자동 적용하지 않습니다. 변환 베이스·템플릿·어댑터·로그는 로컬에 보관합니다.

## 운영체제와 DAW

기본 패키지 테스트·공개 검사·사이트 검사는 Linux·Windows·macOS CI 매트릭스로 실행합니다. 실제 Ollama 작곡과 MLX 학습 사례는 Apple Silicon Mac에서 수행했습니다. 선택적 Transformers/PEFT는 호환 비양자화 HF 모델용 구현이며 이 환경에 PyTorch가 없어 실제 학습은 미실행입니다. GPU·드라이버·모델별 검증은 별도입니다.

네이티브 Logic은 Mac에서 사용합니다. 파일 열기 요청·MCP 관측과 실제 가져오기·컨트롤러·악기·재생·저장 검증을 구분합니다. 이 버전은 Logic 편집 전체를 무인 자동화하지 않습니다. Linux·Windows에서는 MIDI를 내보내 각 DAW로 가져오며 실제 음색은 해당 환경에서 확인합니다.

한·영 공개 기초 자료 구간을 데스크톱과 390px 모바일에서 확인했습니다. 한국어 모바일 화면에 가로 넘침이 없음을 확인했습니다.
